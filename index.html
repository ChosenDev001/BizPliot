Data and privacy

Your business plan is stored in this browser using localStorage. It is not sent to a server by this application.

Clearing browser data, using private browsing, or switching devices may remove or make this data unavailable. Keep a backup. This static prototype has no cloud sync, shared accounts or multi-device collaboration.
